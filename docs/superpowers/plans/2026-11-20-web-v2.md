# Refonte du site (web-v2) — plan de mise en œuvre

> **Pour les agents d'exécution :** sous-compétence REQUISE : superpowers:subagent-driven-development
> (recommandé) ou superpowers:executing-plans, tâche par tâche. Les étapes utilisent des cases `- [ ]`.

**Objectif :** remplacer `web/` (Next 14) par `web-v2/` (Next 16, React 19, Tailwind 4, next-intl 4) portant
l'identité « vitrine gaming SaucisseLand », branché sur des données réelles (bot + web-api), puis basculer.

**Architecture :** d'abord le socle de données (web-api et bot : identifiants en chaînes, réglages en base
modifiables depuis le site, grades, direct,
events, statut d'Hermes, galerie, état-major), chaque endpoint testé. Ensuite web-v2 est créé à côté de
`web/`, servi sur `http://192.168.10.62:3002`, et porté page par page. Enfin, après validation explicite du
propriétaire, web-v2 reprend le port 3000 et `web/` est supprimé.

**Stack :** FastAPI + asyncpg (web-api), discord.py 2 (bot), PostgreSQL 15, Next.js 16 App Router,
React 19, Tailwind CSS 4, shadcn/ui, next-intl 4, better-auth 1.7.27, lucide-react, Vitest, pytest.

**Spec :** `docs/superpowers/specs/2026-11-20-refonte-site-design.md` (maquette :
`docs/superpowers/specs/assets/saucisseland-vitrine.html`, à ouvrir dans un navigateur à chaque tâche
de front : c'est la référence visuelle, section par section).

## Contraintes globales

- Ne **jamais** lancer le bot en local avec le `.env` de prod (il dupliquerait Hermes sur le vrai serveur).
  Les tests du bot ne testent que des modules purs, sans connexion Discord.
- Déploiement : push `main`, puis sur `ubuntu@192.168.10.62:~/Hermes-v2` :
  `git pull --ff-only && <migrations éventuelles> && docker compose up -d --build`.
  Migration : `docker compose exec -T db psql -U $PG_USER -d $PG_DB < db/migrations/<fichier>.sql`.
- web-api reste interne ; le navigateur passe par `/api/proxy/[...path]` (qui pose `X-Client-IP`).
- Identifiants Discord : **toujours des chaînes** dans le JSON consommé par web-v2.
- Couleurs : fond `#0C0E1A`, panneaux `#13162A`/`#171A2E`, violet `#9B6BFF`→`#6E5BFF`, cyan `#3FE0F0`,
  bleu `#4D7CFF`, orange `#FF8A3D`, vert `#3BD16F`, texte `#EDEBFA`, atténué `#9A97B8`. Sombre uniquement,
  un seul dégradé continu sur toute la page.
- Polices : Bricolage Grotesque (titres, 700/800), Instrument Sans (texte).
- Grades : Recrue Cocktail 1-2 · Caporal Chipolata 3-7 · Sergent Merguez 8-14 · Lieutenant Toulouse 15-24 ·
  Colonel Saucisson 25-44 · Général Saucisse 45+. Source de vérité : table `grades`.
- Courbe XP : niveau N atteint à N²×100 XP ; `level = max(1, int(sqrt(xp/100)))`.
- `prefers-reduced-motion` : toute animation (bandeaux, compte à rebours animé, particules) s'arrête.
  Accessibilité AA, focus clavier visible.
- Logo et mascotte non inventés : emplacement réservé. Visuels de jeux : emplacements stylés.
- Aucun chiffre fictif présenté comme réel ; les exemples portent l'étiquette « Exemple ».
- Aucun élément répété entre l'accueil et les pages dédiées ; l'appel final « Rejoins les Généraux
  Saucisses » n'existe que sur l'accueil.
- Français seul ; structure next-intl conservée (`messages/fr.json`).
- Tout réglage du serveur (salons, rôles, seuils, liens) et tout contenu (jeux, règlement, mentions,
  grades, état-major, galerie) se modifie depuis l'admin du site ; `.env` ne garde que secrets et
  infrastructure. Un salon réglé mais absent est créé par Hermes.
- Commits en français, terminés par `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Points d'attention de relecture

1. **Bot hors ligne ou lent** : `/live`, `/events`, `/hermes/status`, `/staff` doivent répondre en moins de
   2 s avec les dernières valeurs connues (`stale: true`) ou une liste vide, jamais une 500 qui casse
   l'accueil. Tests : tâches 6, 7, 8 et 10 (`test_*_bot_down`).
2. **Identifiant Discord > 2^53** renvoyé par n'importe quelle route : doit arriver intact en chaîne.
   Test : tâche 1 (`test_large_int_becomes_string`, `test_nested_lists`).
3. **Fichier piégé dans #galerie** (extension `.png` mais contenu autre, ou > 10 Mo) : refusé sans
   écriture disque. Test : tâche 9 (`test_sniff_rejects_fake_png`, `test_oversize_rejected`).
4. **Membre sans XP / niveau 0 / niveau 200** : un grade est toujours trouvé (Recrue pour < 1,
   Général pour tout ≥ 45). Tests : tâches 4 et 5 (`test_grade_bounds`).
5. **Description d'event sans `XP:`, ou `XP: abc`, ou `xp : 200`** : récompense absente (`null`) ou
   lue sans tenir compte de la casse et des espaces ; jamais d'erreur. Test : tâche 7 (`test_parse_xp_*`).
